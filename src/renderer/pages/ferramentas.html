🛠️ Ferramentas de Administração

📅 Fechamento Mensal

Ao fechar o mês, todas as movimentações (entradas, saídas, contas e devoluções) do mês atual serão arquivadas e removidas do caixa ativo. Os saldos das contas serão atualizados para o próximo mês.

⚠️ Esta ação não pode ser desfeita. Recomendamos fazer um backup antes.

🧹 Limpar Todos os Dados

Esta ação remove permanentemente todos os dados cadastrados: clientes, orçamentos, caixa, contas, agendamentos e demais registros do sistema.

⚠️ ATENÇÃO: Essa operação é IRREVERSÍVEL. Faça um backup antes de prosseguir.

💾 Fazer Backup Manual

Faça um backup completo de todos os dados antes de qualquer limpeza.

🔄 Atualização do Sistema

Verifique novas versões publicadas e atualize sem reinstalar manualmente.
